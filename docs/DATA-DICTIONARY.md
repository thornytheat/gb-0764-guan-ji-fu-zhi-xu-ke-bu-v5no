# 授权材料与页数定义

- CSV 固定字段 `entry,action,received,institution,issn,pages,target`，可重排列序。收件使用 ISO 公历日，无时分秒。词法哨兵 `-`、`N/A`、`NULL`、`未知` 和必填空串进入隔离。`copy` 要刊号和页段，目标留空。`cancel` 要原订单编号，刊号和页段留空。
- 流水号和机构号均为字符串，前导零有意义。CSV 原件支持 UTF-8 BOM、UTF-8、GB18030。行号取记录起行。表头重现只计分段；同流水号同字段重复保首行，字段有异则整组留证。空文件、全空、只有表头分别报错。
- `authority.json` 是随项目发布的持权方条款、刊号别名、机构及联盟与额度池。历史 ISSN 和馆别名映射必须唯一。没有刊号或机构依据的订单待证，缺少当日可用授权的订单拒绝。
- 有效日为左闭右开。机构专属优先于联盟许可，再到公开许可；同类高修订号优先。同级同修订号多条有效时待证，返回候选编号。多个版本可以共享额度池。
- 输入页段为正整数闭区间，如 `1-5;4-8`。内部用半开区间，合并相接与重叠，再裁到刊物页界。优先扣最低可用页。越界拒绝与额度不足单独记页。
- 复本按合印组共用一份印件：同一年度、同一馆、同一刊物且同一选定条款的订单同组；不同馆、不同刊物或不同条款各自分组、各自扣页，绝不共授权。
- 组内以获准页并集管理额度。新单只对并集之外的新增页申请额度，已被别单获准的重叠页随复本共用，逐单都记为获准但不重复扣页；额度不足时新增页从最低页开始满足，未满足页记 `QUOTA`。每条订单分别给出 `shared`（共用获准页）与 `newly_charged`（本次新扣页）。
- 撤销按引用计数退页：被撤订单的获准页中，仍有组内别单获准的页先不退（`shared_kept`），最后一单撤销、页成为无主页时才把实印页释放回额度池（`restored`）。额度池占用恒等于各组当前并集页数之和，实际合印几页就按几页对账。
- 以收件日期与原行号顺序重放整份卷宗。同机构、同年度且曾实际许可的订单允许撤销一次，只返还实际许可页。原裁决保留。当年额度池限额等于有效占用加可用额度。毛许可（各单获准页之和）减撤销返还等于有效占用加共用留存。
- 已采信的复本订单满足申请页等于许可、拒绝与待证三项相加；许可页在订单之间可重复计数，额度池只按并集扣一次。隔离及重复流水排除在页数核对之外。
- 每次归卷独立复算。客户提交撤销或新增订单时需提交完整卷宗。档案键由输入摘要、持权方目录摘要和规则参数生成。签发印摘要为凭证内容的 SHA-256；落印按卷号幂等，重试取回原凭证，不产生第二次扣页。
